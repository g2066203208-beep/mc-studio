# Boss P0 — 真正承重的四足基础模型（Sable/Rapier）

**当前任务：证明真正由脚与地面接触托住有质量的身体。不是步行动画。**

## 结构（全部 Minecraft 原生方块）

在 Sable 的同一个、真正参与 Rapier 重力与碰撞的 `ServerSubLevel` 中摆放 17 个实体方块。

- y=2：3×3 铜机身，共 9 个碰撞方块，正面一格红石灯、中央铜块，其余为切制铜块。
- y=1：四角 `deepslate_bricks` 承重立柱，共 4 块。
- y=0：四角 `iron_block` 脚垫，共 4 块。
- 结构中空；没有地板下轮子、不可见站立判定、反重力、不断回写的位置或“单纯转模型”。
- 每条腿在 (x,z)=(0,0)/(0,2)/(2,0)/(2,2)，其碰撞箱跟随同一个真正刚体。**这是第一阶段的刚性腿，不是已完成的关节腿**。

## 用户如何在真正的 Minecraft 世界召唤它

安装项目 NeoForge `reme_studio` 测试 Mod，必须同时使用：
MC 1.21.1、NeoForge 21.1.248、Create 6.0.10、Aeronautics 1.3.2、Sable 2.0.6。站在一片已经加载的**水平实心地面**，管理员或单人作弊模式输入：

```
/rpms bossrig
```

模组会在玩家面向的约五格外，根据地形表面高度，于地面上方生成一个真正的 Sable SubLevel，物理重力让它落下来，四脚与地面碰撞托起躯干。用自己的 MC 客户端可以直接围着模型看、敲它和检查脚垫。其它环境（坡地、半砖、水中等）尚未通过测试。

## 物理上脚如何真正托起身躯

不是“腿提供一个向上的飞行力”。重力施加于所有方块组合出来的刚体；Rapier 通过脚部 4×铁块碰撞形状与地面求接触、法向冲量及摩擦。四脚下方地面反力之和抵消躯干+腿质量的重力，脚分布在四角还可抵抗翻滚的力矩。支撑稳定的条件是质心垂线落在当前接触脚形成的支撑多边形内，且摩擦能提供阻止侧滑的水平力。

因为 P0 的腿与躯干是同一个刚体，支撑力通过刚体整体传递；目前没有髋、膝扭矩计算，**不能宣称腿关节已经承重**。下一阶段将把上腿和下腿拆成独立 SubLevels，以真正的 `RotaryConstraintHandle` 串联，检查负载和真实角度，然后才谈抬脚、站起与行走。

## 不能靠演示动画作弊的 GameTest

`BossPhysicalRigGameTests.fourFeetActuallyCarryBodyWeight`，直接运行 Minecraft 自带 NeoForge GameTestServer：

1. 在真实 Minecraft 世界铺设 5×5 实心石质地面。
2. 在上方生成前述 Sable 17 方块四足刚体，检查质量 `MassTracker.getMass() > 0`，记录真实 Pose 和垂直速度。
3. 经过 87 个服务器 Tick，要求重力带来实测下落、四个脚垫接近地面顶面、垂直速度降至小于 1.2m/s。
4. **同一刚体物理移除所有 8 个脚部实体方块**，再经过 49 个 Tick；要求机身从原先高度额外下落超过 0.85 格。若没有下落则测试失败。
5. GitHub Actions 只有在日志出现 `RPMS_NATIVE_PASS fourFeetActuallyCarryBodyWeight REAL_COLLISION_AND_GRAVITY` 时才算过关。

如果测试因 Sable 的质量缓存、子世界保存、碰撞地图刷新或形状而失败，就明确报告与修复，不能修改测试要求来伪造成功。这是“脚托着身体”的**因果验证**。
