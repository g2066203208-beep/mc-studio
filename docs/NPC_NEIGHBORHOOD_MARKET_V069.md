# REME NPC 0.6.9-dev：居民经济、NPC 自主采购和七日市集

## 版本与兼容
- Minecraft 1.21.1 / NeoForge 21.1.262 / Java 21，仍采用历史 `reme_studio` 注册 ID，优先保护 v0.6.8 及旧版存档。
- 项目隔离：本 PR 仅开发 NPC 生活与社会玩法；不涉及 PEAK、WorldSeam、RPMotion、ShipRepair、沉浸车辆模型学习。仅继承 NPC 真实床位 PR #92；如用户要在同一整合包运行 PEAK，需要单独 Mod ID 与数据迁移方案。
- 代码与真实游戏测试：`NeighborhoodMarket.java`、`ShopCounter.java`、`MarketEconomyGameTests.java`，Java 21 的 GameTestServer 原生版本以 PR Actions 运行结果为准。

## 真正新增的可游玩系统

1. **NPC 顾客自己找商店**：`LIVE` 地区居民饥饿（需求 <=65）、有真正绿宝石、没有合适现成食物，且没被追捕/惊吓/拘留/睡觉、没有优先挖矿/长途商队任务时，只检索 18 格内加载中的同区域、非敌对 NPC 店员。真实寻路到柜台，在近距离和已开放营业的店员处自动付款；不瞬移、不强制加载区块。
2. **店员真的收购农夫产出**：只有 `SHOPKEEPER` 处于 `WORK` 班次、现有营业背包食品不足 4 份、真的持有 >=1 绿宝石时，才能与附近 FARMER 以 **1 绿宝石购买真实 3 个胡萝卜**，农夫收到同一个绿宝石。店员会寻路靠近农夫。
3. **物品与资金守恒**：两名 NPC 的 36 格背包先分别模拟移除和增加物品，只有付款有钱、接货还有空间、本人非敌对/被关押且双方足够接近时才双边提交。购物单价固定 1 绿宝石/1 已存在的面包、苹果或胡萝卜；商店按顺序售货。全满、缺货、资金不足或欺诈信誉较差均拒绝且不扣除一件物品。
4. **贸易成为关系**：每次真实交易对双方的有限社交记忆记一条 `TRADE`（+2 信任），写入原 NPC NBT；不凭空修改其他全城 NPC 的声誉。
5. **每七个游戏日有一次真实街头市集**：游戏世界日期第 2、9、16… 天的 9000—11000 tick（允许居民作息偏移）附近同区域居民在有时间、没遇险时向真实店员聚集，在身边交流、共享已有见闻、恢复部分社交需求。保留 2400 tick 冷却避免瞬间刷好感。这是 NPC 世界 AI 行为，不是 GUI 演出或生成大型建筑。
6. **无作弊指令 `/npc market`**：玩家可查看周围实际加载 NPC 中的门店数量、正在柜台营业数量、可售商品真实数目、手上有钱且有购物需求的居民数、农夫数及是否当前市集时段。并行保留 `/npc info`、`/npc bed`、`/npc shopkeeper`、`/npc shopstock`、`/npc jail`、`/remecheck`。

## 如何在游戏里亲眼看见

1. 进入 **1.21.1 / NeoForge 21.1.262 / Java 21** 新建测试世界，确认 `/remecheck` 有答复、`/npc` 在帮助里出现；必须使用 v0.6.9 JAR（不是 main 的通用 Mod）。
2. 开作弊输入 `/npc spawn 店长`，靠近这名归属自己的 NPC 输入 `/npc shopkeeper` 和 `/npc setwork`，保证营业柜台地面能通行。手持绿宝石正常右键 NPC 可把自己的一枚绿宝石交给 NPC 的真实背包。
3. `/npc spawn 农夫`、`/npc farmer`，向自己的农夫右键交给至少 3 个真实胡萝卜。店长有钱且营业库存不足时会在工作时段自己去找农夫付款采购。
4. `/npc spawn 顾客`，`/npc resident`，向这名 NPC 交给一枚真实绿宝石，且保证其真实背包无食物、饥饿需求 <=65。它会在同地区附近搜索已营业、实际有库存的商店，走过去购买。
5. 输入 `/npc market` 查看店铺、库存、营业情况，`/npc info` 看最近 NPC 的生活状态与行为。游戏日数的市集活动不要求玩家手动触发。
6. **不要在三个 NPC 身上乱装其他工作室的同 ID `reme_studio` jar**；用户 HMCL 的真实 Mods 目录仍需按照当前启动实例确认。

## 真实测试范围

`MarketEconomyGameTests` 包含：
- 农夫（6 胡萝卜）→店长（出一颗真实绿宝石收 3 胡萝卜）→居民顾客（自己花绿宝石买面包），逐项核对真实库存货币双边守恒与 NBT 信任。
- 店员钱箱满、顾客背包满、店铺没有现钱、距离超限、店主不营业、因真实偷窃证据拒绝交易等失败路径。
- 每七日市集窗口逻辑与近场交谈、冷却与社交记忆。
- 16 名居民争购 12 份实际食品，额外 4 名不得被收费、不得出售不存在的食物。
- 非手工调用交易函数的 180 tick 原生服务器居民自动购买测试：核实支付绿宝石和库存真实变化。
- 原有 58 项 GameTests（24,000 游戏 tick 真实床位睡醒、警察逮捕和物品守恒等）继续跑回归。

## 尚未完成，不能谎称实现
- 这不等于无人参与的闭合宏观经济或繁荣的大城市。农夫需要真实收获物资、店铺需要已经得到的绿宝石；不会凭空给 NPC 发工资/生成金钱。完整自动房屋、商场、餐馆、图形交易菜单、动态物价、税收、城市企业竞争尚未实现。
- 街头集市是真的本地 NPC 社交/活动，但没有新的摊位方块、NPC 表演、游艺设施和广播喇叭，目前仅有已存在商店的聚会。
- 警察/盗匪系统仍以有限近场行为和单项原生 GameTest 为依据，完整自动押送进有门禁牢房未长时验收。
- 原生 NeoForge GameTest 是真实 MC 逻辑测试，不等于真人在真实画面玩了几小时；GUI 客户端 /npc market 冒烟需额外检查截图/日志；完整多模组 HMCL 兼容与 100—200 NPC p95 MSPT 未测。
