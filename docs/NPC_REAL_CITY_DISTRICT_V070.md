# NPC 0.7.0-dev：真实 Minecraft 城市建筑与街区（试验性城市工作室）

> 目标版本 Minecraft 1.21.1 / NeoForge 21.1.262 / Java 21。功能分支 `feat/npc-real-city-district-v070`，PR #97，在 NPC 市集 PR #93 之上，不触碰其余 5 个工作室。

## 为什么此前截图里根本没有城市

此前 `/npc demo` 只生成六名居民，不生成道路或建筑；市集 GameTest 用的是独立测试场景，不能证明玩家实际看到都市。只有一个 NPC 的雪地截图不能冒充城市演示。新 `/npc city demo` 做的是真实 MC 原版方块、实体、库存，并单独跑 GUI 城市拍摄。它是**管理员创建的城市演示**，不是自动 NPC 生存模式造城。

## 立即试玩

1. 在 **全新测试世界** 的平整空地上，确保 41×41 地面下方均有实心方块，地表以上 11 格完全是空气、无树、雪或建筑，且全部区块都已加载。为了保护旧世界，这些条件一个都不能跳过。
2. 使用拥有 OP/作弊权限的玩家站在将来十字路口中心执行 `/npc city survey`。失败时会报告被占用的坐标，不会动任何已有方块。
3. 确认场地可用后执行 `/npc city demo`。它一次性放置原版方块、柜台、床、路灯等，并建立 12 个有生活 AI、职业、实体库存和姓名的 NPC。然后输入 `/npc market` 检查现场店铺和买家。
4. 在旁边观察二层商场的真实储藏箱、天窗/灯带、两侧街道、人行道、斑马线、路灯、警局铁栏杆、钟、市集摊位与原版音符盒；所有素材都是原生 Minecraft 方块。
5. 该指令仅为**新世界展示**，不会强行平地或替换/删除玩家建筑；重复执行会拒绝。没有批量撤销，需要先备份世界或在独立测试世界使用。

## 41×41 的真实设计构成

- 纵横双车道：41×41 有 5 格宽十字街，灰色混凝土真实地面、黄线、白色斑马线，两侧平滑石板人行道和海晶灯路灯柱。**道路预建，不是居民脚步自然铺成沥青路。**
- 西北地块：双层购物中心，石英地板、明亮玻璃幕墙、二层实际楼板、梯道、柜台、三个真实木桶/箱子展示货架、遮阳雨篷、橙金色屋顶标识与两名 NPC 店员。NPC 的销售实际扣除库存和玩家/NPC 绿宝石。
- 东北地块：两栋不同外立面的联排住宅，真实橡木门、床头+床尾两个方块的原版红床、箱柜等。
- 西南地块：警局与铁栏杆拘留区，工作台、警钟，两个有独立执勤与拘留位置的 GUARD 居民。锁门、羁押全程守法动画和押送仍不成熟，不能因有铁栏杆就宣称司法系统完成。
- 东南地块：真实树木/石板路径/喷泉（无洪水的水炼药锅）、红黄篷市集摊位、音符盒与公园设施。
- 12 名 NPC：店长和店员、烘焙店员、两名执勤守卫、两名携真实胡萝卜的农夫、四名有绿宝石的顾客/居民、快递员。为**创意演示**明确给他们初始库存，此后 NPC 正常执行真实生活 AI；不能说他们在生存模式中自己挖矿造好了整个街区。
- 所有行走、开店、犯罪、睡眠仍来自之前 NPC 模块，没有在 Python 或网页里模拟 NPC 的行为。

## 真正的自动化验收

- `CityDistrictGameTests` 在真正的 NeoForge 游戏服务器中创建并检测道路连续性、斑马线、路灯、二层商场、真实 ChestBlockEntity、真实 bed HEAD、警局铁栏与警钟、真实音符盒、12 名 NPC / 店员与库存、重复生成必须安全失败，另单独测试已有钻石方块不得破坏。
- `.github/workflows/npc-city-visual-e2e.yml` 启动真实 Java NeoForge 客户端，进入**一次性专用新世界**，测试脚本用原生 `/fill` 专门准备 41×41 平坦场地（仅测试环境，**不是演示城市指令自行铲平世界**），然后实际输入 `/npc city survey` 和 `/npc city demo`，用 Minecraft 自由相机拍两张真实俯视图、街道图与市场状态，失败必须上传日志和截图证据。
- Minecraft 游戏的 GUI 截图/日志应由对应成功 GitHub Actions artifact `npc-real-city-1-21-1-neoforge-3d-screenshots` 下载核实；不能以工作流正在排队/失败当作通过。

## 实际尚缺、下一阶段需要专业开发

真正的**生存版 NPC 自己盖城市**、逐建筑材料消耗、真实地皮审批、自动选路和路网扩建、百名 NPC 高并发效能、大型三维购物中心、动态道路红绿灯汽车、电梯、医院、银行、学校、餐厅、户籍税收、城市治安长时可玩系统目前**均没有完成**。本版本才是最小可视化、可测试的城市起点，不应称完美城市。
