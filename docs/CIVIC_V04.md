# Living World v0.4 — 信息传播、目击法律、个人善恶声望、有限委托

版本：Minecraft 1.21.1 / NeoForge 21.1.248 / Java 21。工作分支 `feature/living-world-civic-v04`，在 v0.3 社会系统基础上继续开发。

## 本版真实功能
- `CivicMind`：每个 NPC 保留最多 48 条事件记录（稳定的 UUID、行为人、最初目击者、类型、发生游戏刻、传闻跳数、直接目击标记）；玩家攻击 NPC 后，受害者与 12 格内真正能看到攻击者的 NPC 分别直接记忆。遇见时才交流；同地区、非敌对、可信且愿分享消息的居民传递至多 3 条最近一天内的*原始直接目击消息*；传闻比直接目击权重低，一条事件不能通过循环重复刷声望。没有全世界广播，异地实体或卸载区块不自动传闻。
- `CharacterProfile`：诚实/正义/好奇/同理心（0-100）与先前勤奋/社交/谨慎同时持久化。诚实/同理影响是否愿意传播，好奇和正义用于某些行为倾向，正义高的守卫识别嫌疑人时会警告但不滥杀、没收。
- **善恶与声望**：NPC 对行为人的声望来自自己目击或听闻的善恶事件：袭击、盗窃（底层支持但尚未接入真实开箱盗窃监听）、帮助、赠礼、兑现委托。严重点的攻击能导致 NPC 的拒售与法律嫌疑状态。这个指标是本地*认知声望*，不是整个国家共享的全知通缉名单。
- **委托**：NPC 主人用背包中的真实绿宝石发布有限任务，绿宝石即时扣除进入委托保管状态；玩家领取后拿着真实指定商品送回 NPC，拥有空余格且 NPC 背包能完整容纳时，NPC 扣走商品、玩家收到实际储备的绿宝石；同一单不可多次领奖；任务取消归还 NPC 原有库存；NPC 死亡时未兑付的委托绿宝石掉落。任务、领取人、剩余奖励持久化。
- **GameTest**：添加 NeoForge 真实游戏服务器框架下的自定义实体生成与 NBT 往返结构测试，以及独立 GitHub Actions 工作流。测试是否成功必须看 Actions `Server GameTests (experimental)`，不能只凭构建成功判定。

## 玩家测试命令

| 命令 | 说明 |
|---|---|
| `/npc demo` | 创建六名试验居民并初始化不同社交个性 |
| `/npc law` | 查看最近的 NPC 对你的直接/间接声望和法律状态 |
| `/npc news` | 查看最近 NPC 已知的目击事件数量与二手传闻数 |
| `/npc commission WHEAT 3 2` | 你的最近 NPC 发布收 3 个小麦、赏 2 枚绿宝石的任务，预先从该 NPC 背包扣 2 绿宝石 |
| `/npc job` | 查看最近居民的任务及当前状态 |
| `/npc accept` | 最近居民任务 OPEN 状态则承接，坏声望可能被拒 |
| `/npc deliver` | 持规定数量的物品，给最近居民交付、获取已支付奖励 |
| `/npc canceljob` | 只有 NPC 主人能取消未完成委托，退款给 NPC 实际背包 |
| `/npc info` | 显示最近自有 NPC 的状态、关系、目标和当前任务 |

命令通常作用于 16 格内最近 NPC；发布和取消委托仅能对自己创建的 NPC。用 `/npc setwork` 等旧指令安排已建的房屋和工作地。

## 必须测试的行为
1. **多 NPC 见证**：玩家攻击一位普通居民，受害者亲眼记住，附近看得见玩家的其他居民会形成同一事件的目击记录，墙后的居民不应全知。
2. **谈话才传递**：与没目击的 NPC 见面后，只有同地区且信任你的目击者/其朋友才有机会分享。二手消息不能再无限传染第三手。
3. **重复举报**：不能因为多次讲述同一条传闻刷出无限通缉指数。该地区与另一地区声望可以不同。
4. **委托资金守恒**：发布 2 绿宝石赏金立即减少 NPC 背包中 2 枚绿宝石。交付小麦后商品进入 NPC 背包、2 枚绿宝石到玩家背包；重复 `/npc deliver` 必须失败；没空格、没有足够物资、错误领取人也必须失败。取消应退款且不得复制。
5. **重载测试**：保存世界、退出重进，证据、来源、性格、任务领取人、委托资金状态仍在。已完成委托不能重新付款。
6. **运行环境**：NeoForge 游戏内 GameTest 通过之后，还必须在专用服、客户端和完整 222-mod 整合包复测 TPS 与存档。

## 未实现与风险
- **不是正式司法系统**：法律只是 NPC 各自的目击证据、善恶评价和守卫非致命警告。没有法庭、逮捕、保释、罪名管辖、领土警局、跨地区的官僚信息网络、财产盗窃归属和判罚执行；不自动攻击玩家。
- 玩家开箱或破坏领地的盗窃认定未连接 NeoForge 事件。底层枚举包含 THEFT，但不可说真实偷窃事件已可识别。
- 委托只支持 WHEAT、BREAD、CARROT、POTATO 单物资交付。并非多阶段开放式任务链、路线报酬或自由语言接单。
- 真实钓鱼、采矿、真正国家治理/动态外交、离线 NPC 世界模拟和婚姻家庭仍未完成；见 [Issue #13](https://github.com/g2066203208-beep/mc-studio/issues/13)。
- 测试中请使用**独立存档**。历史版本的农田与建筑操作尚未接入全部第三方领地保护 API。
