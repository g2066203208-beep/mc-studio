# REME Native Seam · 自研垂直跨维度引擎

## 设计边界

这不是 Immersive Portals 的适配器，不把任何第三方传送门 Mod 作为运行时依赖。本项目实现自己的层间空间映射和服务器端跨维度穿越。目标仍是**视觉+物理真正无缝**；本分支的 V1 只是底层和渲染原型，不能宣称完成完整无缝世界。

- 世界仍为 Minecraft 原本的独立 `ServerLevel`，不会复制/移动整个存档。
- 垂直拓扑：末地底部 ↔ 主世界顶部 ↔ 主世界底部 ↔ 下界顶部。
- X/Z 坐标 1:1；Y 保留穿越平面的相对距离；玩家速度、角度、坠落距离在跨界后恢复。
- 允许 OP 手动给测试存档启用/停用；设置保存在该存档的 `SavedData`。
- 禁用状态下不改游戏世界；启用后只处理越过边界的玩家，不自动凿穿基岩，也不自动覆盖原有传送门。

## 测试命令

```mcfunction
/reme seam status
/reme seam probe
/reme seam enable
/reme seam disable
```

先做备份，在单独测试存档启用（权限 2）。采用创造/旁观穿越边界时注意：**本阶段不会让现有区块基岩自动消失**；任何无缝地形连接必须后续单独改世界生成或明确执行安全改造。末地和下界原版高度、地形布局也并非自然拼接。

## 2026-10-21 · 自适应边界视野 V2

- 引入自主 `SeamFrameState`：逐玩家/逐维度/逐边界区域的版本化增量缓存，客户端丢弃乱序、异作用域数据，并在禁用后清屏。
- 近场从 13×13×8 扩展到 13×13×12；每 5 tick 增量更新，空闲以心跳维持，新增天空光/方块光亮度，视锥及遮蔽裁剪。
- 远场 LOD：19×19 列沿真实目标维度地形取样，最高深度 320 格；顶部优先查询高度图，底部有限扫描。每秒更新一次，只发送有证据的真实表面方块；没加载的远端区块不会被远景采样强制生成。
- 性能预算：每次预览最多强制生成 1 个远端区块；同一玩家相机的小幅移动按 8 格区域量化以减少完整重发。
- 限制：远景只是稀疏表面代理，不是完整区块渲染；没有水体、块实体、远程实体、天气及着色器多维上下文。仍须实际客户端和专服验收。


## v0.5.0-dev · Minecraft 区块段底层（2026-10-21）

本版本加入**自主**区块段流与独立的客户端维度区块缓存，仍保留旧的稀疏预览作为远距离 LOD。

- **原生区块结构**：从已加载的 `LevelChunkSection` 读取 16×16×16 方块状态，用本项目的 `SeamSectionCodec` 进行区块专属 Palette 与 64-bit 位压缩。每个包附带目标维度、源维度、区块段坐标、接缝 Y 坐标、单调版本号和远端光照。严格限制调色板/数组大小。
- **区块段调度**：每 5 tick 最多编码一个 3×3×2 预览范围的区块段，只采样现存目标区块；相同内容不重发；同一客户端作用域变更清理旧区块，最多缓存 48 段。单独轻量心跳防止无变化时缓存过期。
- **渲染路径**：一个段更新时计算可见方块面，再以相机视锥和距离进行二次裁剪。现阶段使用 Minecraft 原生 `renderSingleBlock` 模型绘制和光照，**还没替换成按 RenderType 批处理的自研 GPU Chunk Mesh**。
- **空间边界修正**：下界逻辑天花板采用 Y=128，而不是空旷的最大建筑高度 Y=256；末地底部和主世界上下沿仍采用原本世界边界。
- **新世界接缝（另行授权）**：`/reme seam terrain enable` 只在 `/reme seam enable` 已开启时，处理**新生成区块**：主世界地板 -64 到 -60；下界基岩天花板 120 到 127。只将这一区间内的基岩替换成空气。存档配置默认关闭；旧区块完全不自动修改。关闭使用 `/reme seam terrain disable`，不逆转已生成的地形更改，使用前必须备份。
- **实体迁移性能与安全**：从世界实体全表扫描改为 `EntityTickEvent.Post` 局部判断；跨界前检查目标落点碰撞空间，若旧区块仍被基岩封闭则拒绝迁移而不是将实体嵌进墙里。
- **新 JUnit 用例**：调色板字宽边界、4096 状态往返、非法包结构、缓存过期版本/错维度/清理/LRU 上限、Y128 和新生成地形范围。

**尚未完成：** 替代原版客户端单维度活动 `ClientLevel` 的多维世界切换；平面深度遮挡/完整流体/远端实体的原生 Chunk Renderer；彻底取消原版 Respawn 换维造成的重建画面；新旧区块拼接、Sable 刚体和实际客户端验收。编译通过不能代表已无缝游玩。
