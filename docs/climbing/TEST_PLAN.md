## 2. 抓点检测测试矩阵（M0）

六方向：
- 正 X / 负 X / 正 Z / 负 Z：垂直侧墙；
- 正 Y：平地、平台顶面；
- 负 Y：实体方块底部、悬挂天花板；
- 任意旋转法线：45 度倾斜 Sable 结构、绕任意轴旋转。

测试方块类型：
- 完整石块、木板、玻璃、铁块、树叶；
- 半砖、楼梯、栅栏、围墙、活板门、末地烛、台阶边缘；
- 两个贴近的方块、门与活板门改变状态、动态挖掉被抓方块；
- 空气、流体、火、无碰撞装饰方块（不得误判为承力抓点）；
- 可抓但背后有实体阻挡 / 隔两层墙 / 穿墙射线（应拒绝），极小碰撞片（按参数决定抓握）。

断言：命中点必须落在原始真实形状表面容差内；世界法线与实际形状相符；不能命中空气/遮挡后方目标；同一个候选形状在 6 个方向查询逻辑一致。

## 3. 操作与身体运动（M1）

- 进入攀爬模式，左键只触发左手、右键只触发右手；正常模式还原挖掘、攻击、右键使用与放置。
- 单手抓墙后玩家受单锚约束；另一只手空闲；松开抓握手后重力恢复。
- 双手抓不同位置，释放其中一手仍可悬挂，释放最后一手立即掉落；按键快速交替无复制锚点、假抓点、无限抬升。
- 天花板下表面悬挂，可沿表面横移，不穿透天花板；双手松开坠落。
- 平地贴地抓握，玩家不无故飘起；匍匐穿越 1 格高空间需单独验证碰撞箱切换。
- 墙角、地板到墙面、墙面到天花板等法线改变时无相机翻转、卡死、穿越碰撞箱。
- 高处惯性抓取：有最大手长、速度保留但不以超大速度穿墙。
- 快速转向、鼠标失焦、打开菜单、死亡、传送、切维度、退出世界均释放并清理状态。
- 手拿方块、镐、盾、食物时，模式内不会误挖掘/放置或复制物品；模式外回归原版。
- 原版手臂和原皮肤保持正常，画面中两只手可区分；动画可以简单，不成为物理正确性的替代品。

## 4. Sable 动态结构（M2）

结构状态矩阵：
- 静止 Sub-level 与世界静态方块抓握效果一致。
- 沿 X/Y/Z 平移；结构有匀速、加速、减速、急停。
- 绕 X/Y/Z 旋转；连续转弯；玩家握点在接近旋转中心及远离旋转中心位置。
- 旋转与平移同时进行；向下倾斜导致原墙壁表面变成天花板或地板。
- 玩家双手分别抓同一船体两个方块，或不同结构；需要有可预测的超约束处置。
- 结构被拆解、方块被挖掉、子世界卸载、进入无效世界；应释放对应手并安全恢复速度，不崩溃。
- 从动态结构松手：应继承合理切向速度与相对动量，不保持“停在空气里的锚点”。
- 动态结构局部点 -> 世界点 -> 局部点往返误差量化记录；插值帧不应有可见跳点。

每次记录：实际锚点局部位置、每 tick 世界预测位置、渲染插值位置、玩家实际位置、校正次数、最大位移误差与碰撞穿透次数。
未实测之前不声称“已经没有抖动”。

## 5. 联机与安全（M3）

- 单机集成服务器 / 本机 dedicated server / 两名玩家同时抓同一结构分别测试。
- 客户端故意提交超远手锚、隔墙手锚、无效维度或结构 UUID，服务端必须拒绝。
- 高网络延迟、丢包、重复按键事件、客户端帧率波动，不得让一方永久悬挂或产生高速回弹。
- 断线/重连或维度切换后不保存已失效抓握。
- 旁观/创造/飞行/坐骑/睡眠/游泳/死亡等玩家特殊状态明确关闭或兼容并测试。
- 使用不同客户端配置时服务器规则仍一致；禁用 Mod 的客户端不能连接需要该 Mod 的服务器，需通过 Mod 元数据明确依赖。
