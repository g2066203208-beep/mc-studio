# Sable Hands V2 / 原版弓单手演示

目标版本：Minecraft 1.21.1 / NeoForge 21.1.248 / Java 21 / Sable 2.0.6。
本分支预计以 0.3.0-alpha.1 发布（必须以最新 GitHub Actions 产物核实）。

## 用户测试方法（务必使用独立存档）

1. 玩家主要惯用手设置为右手（Minecraft 默认）。**右手对应主手，左手对应副手**。
2. 将一把原版弓放进左手副手栏，把箭放入背包。可以先用 F 交换主副手（或在背包里拖入）；保持右主手空。
3. 走近石头/木头等墙壁，约 2 格内准星看向墙。**右键单击一次锁住右手**，放开鼠标不应松手；再次右键释放。
4. 右手抓住时，**左键按住用副手原版弓蓄力，松开左键发射**。不应松开右手抓点。原版弓箭数量、蓄力、声音与耐久机制不应被替换。
5. 左手空时左键单击可锁定/松开左手抓点；两手抓住时 WASD 尝试沿表面移动。
6. 右手抓墙，左手副手换成雪球/鸡蛋/末影珍珠/食物等，再用左键测试原版使用流程。
7. G 是紧急释放双手；无须先 G 进入攀爬模式。
8. 只在蹲下或已离地时允许地面上表面的点击抓握，避免正常挖掘/互动被抢占。

## 已编码逻辑

- 0.2 alpha 原本 G 模式/长按抓墙改为左右鼠标**单击锁定**；
- 新增服务端副手 Use / Release Intent；右手有效抓握是左手使用物品的前提；
- 射箭沿原版 ServerPlayerGameMode.useItem 和 Player.releaseUsingItem，而不是复制生成箭矢；
- 增加“左手持弓，不许强制抓墙/误松右手”游戏内回归测试；
- 保留原版玩家皮肤、手臂模型和弓道具模型；现有 VanillaGripHands 固定偏移动画暂未完成“伸手贴近真实抓点”的需求，第三人称握墙动画也仍需单独完成。

## 尚未验证/需单独实现

- 本分支必须等 CI Java/JUnit/普通 GameTest/带 Sable 集成 GameTest 通过后才可当实验版下载；
- 真实图形客户端的右键锁定/左手拉弓/发射及箭矢位置、第三人称的两手独立姿态；
- 动态 Sable 运动船体的抓点、墙-天花板过渡与发射后坐力、多人同步；
- 使用左利手玩家、复杂道具自定义使用方式和其他 Mod 物品兼容均未测试；
- 目前不支持物品占位动画与弹性身体真实 Rapier 动力学，不能称成品。

最重要的游戏内目标是 **右手抓墙悬挂时左手持弓射出原版箭矢，并且右手仍能承重**。在正式 GameTest 加动态结构以及图形客户端验证前，PR 保持 Draft，不合入 main。
