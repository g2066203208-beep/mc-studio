# NPC v0.7.1-dev 真实城市便利店营业、顾客、逃单与出警验收

目标 MC 1.21.1 / NeoForge 21.1.262 / Java 21。开发 PR #101，在城市 PR #97 之上。不是和其他五个工作室混装的正式发行版。

## 真正可玩的行为

- 原版时间 `dayTime=0` 是 06:00，`dayTime=11000` 是 17:00。店员在日间实际向工作坐标步行，只有在真实柜台附近且正常值班、体力足够时才接受居民购买；17:00 后收银结束，17:00–18:30 尝试真实寻路回家。原版床位睡觉和危险优先于工作。
- 客人是真正的 NPC 实体，背包里有真实绿宝石、饥饿时会到附近加载商店真实付款；一次卖出 1 个**真实**库存面包/苹果/胡萝卜、店员收到 1 绿宝石。没有菜单刷货、直接从别人的箱子偷拿或全球隐形交易。
- 13 名居民的**创意街区展示**中多了一位诚实度为 8、没有绿宝石的居民（`街区逃单者`）。正常居民不会因没钱而被视为小偷。该 NPC 仅在白天实际接近有库存、有店员的柜台时，才可能用自己的手拿走实际库存、不给绿宝石；实际移动离开柜台才形成待报案件。
- **治安因素有真实作用**：近场警卫巡逻密度 0/1/2+ 使其单次尝试逃单的概率分别为 75%/30%/5%。低诚信不等于有罪；还必须有真实货物的零元转移及店员第一手目击记录。没有抢劫就没有报警抓捕。
- 逃单者走出店铺 6 格以后，目击店员呼叫附近 16 格同辖区的、非敌对、能够看见店员的在岗守卫；守卫获得 **UUID 指向的真实案件**，而不是凭全局知晓直接抓人。附近真正存在的原版钟会被敲响。警卫通过真实 AI 寻路追赶，在小于 1.8 格、互相看得见时才执行非致命抓捕；之后目标向已批准的铁栏拘留区自己走过去，当前是限时社区拘留，**尚没有锁门法庭判刑全过程**。
- 商店货架取货、交易、库存和绿宝石均发生在服务器主线程；商品从售货 NPC 背包转进客户 NPC 背包前先用副本模拟，容量不足时两边都不修改；报警严格依照真实第一手证据，不能用谣言直接拘捕。
- NPC 偷窃待报的商家 UUID、事件 UUID、有限期限、报警状态与冷却写进已有存档 NBT；玩家可在现场执行 `/npc city audit` 查看营业/休业店铺、实物库存、有钱顾客、尚携带未付商品的 NPC、已报警案件、巡警追捕任务、在押 NPC 数。该指令是实时周围 42 格的有限半径查询，不是跨维度的虚拟城市统计。

## GitHub Actions 真实验收

1. `.github/workflows/npc-store-justice-soak.yml` 以 Java 21+真实 NeoForge GameTestServer，在**独立世界**跑全部旧回归与新增强制失败测试。要求同时出现 `REME_NPC_REAL_STORE_DAYSOAK ticks=24000`、`REME_NPC_STORE_CRIME_PATH`、`stage=paid_sale`、`stage=unpaid_pickup`、`stage=guard_dispatch`、`stage=nonlethal_arrest`、原有 `REME_NPC_REAL_BED_DAYSOAK`，缺任意项直接失败。
2. `StoreFullDayGameTests` 在 24,000 **真实 Minecraft 世界 tick** 内让独立店员、顾客真实生活，周期检查店铺营业/关店状态、确实收到顾客绿宝石、NPC 生活是否持续，没有用手动调用业务函数冒充每天运行。这里的 24,000 是**游戏日**，不是 24 小时现实时间。
3. `ConvenienceJusticeGameTests` 在真实的 Minecraft 服务器中真实转移货物、验证第一次犯罪证据、模拟已经离店的位置（此单个步骤**由测试工具布置位置，不等于实测小偷从店里走到店外**）、触发报案和警卫接案，再将守卫安排到近身位置测试拘留判定。商品、案件与 NBT 必须守恒；对没有违法的顾客，即使贫穷也不得立案。**此测试尚不等于完整长程追捕与押送到锁牢里。**
4. `.github/workflows/npc-city-visual-e2e.yml` 启动真正的有界面 NeoForge 客户端，进入全新一次性世界，通过原版命令 `/npc city demo` 生成 13 位实际人物，拍店员、警卫、公园居民和逃单者 2 次间隔跟踪照片，并执行 `/npc city audit`。实机截图和 NBT/服务器库存测试分开验收；截图不会自动证明交易、犯罪和司法系统。
5. GitHub Action artifact 里应保存完整原始 JVM 和世界日志、游戏内 RGB 截图。不能拿示意图片、编译成功或只刷出实体冒充游戏内完整体验。
