# Seamless Dimensions — 无缝维度（独立工程区）

> 状态：已预留并隔离开发目录；**尚未完成可运行的独立 NeoForge Mod，也未通过客户端视觉/双维度加载验收**。不要将此目录的存在视为功能完成。

## 独立身份与边界

- 唯一负责的项目：上下相邻维度的**无缝视觉、双维度加载和跨界移动**。
- 工程根路径：`projects/seamless-dimensions/`，计划在此建立**自己的 Gradle/NeoForge 工程、包名、mod id、CI、测试、产物目录**，而不是把代码添加到仓库现有共享 `mod/`。
- 暂定 Java 技术基线：Minecraft Java 1.21.1、NeoForge 21.1.248、JDK 21；升级需单独验证。
- **不可修改** NPC 仿真工程、航空学/机械动力工程和网页建造器，尤其是现存 `mod/` 的 Create/Aeronautics/Sable 探针及 `viewer/rpms/`。确需接口兼容时，通过新工程中的独立适配层实现，并记录依赖版本。
- 单独分支及 PR，按文件路径审核，禁止同时更改其他项目模块。

## 用户要求的功能与验收

1. 维度垂直堆叠：主世界、下界、末地自由上下排序，可添加、删除及重排兼容维度，明确每个维度的高度与边界映射。
2. 跨边界**实际进入另一维度**，双向位置、朝向、速度与实体一致，不能只靠传送伪装。
3. 视野穿越边界时看到邻接维度**真实地形、天空、光照、粒子、实体**，边界处视觉连续；不得仅实现玩家位置切换。
4. 双维度在客户端按视距/预取策略同时加载、渲染及缓存可见区块，避免边界附近重复卸载、闪烁、黑屏或反复加载。
5. 服务端预加载、区块票据与生命周期可控，避免永久加载泄漏；提供性能与兼容性指标。
6. 支持含自定义世界高度/Mod 维度的边界映射、配置 UI、中文本地化与安全回滚。

## 验证不可混淆

- 编译通过 ≠ 可进入世界 ≠ 跨维度移动 ≠ 视觉连续 ≠ 稳定双维度加载。
- 最低游戏内验收：NeoForge 开发客户端实测从主世界向上至末地、向下至下界及原路返回；边界两侧提前看见真实对侧世界；飞行、跑步、载具/实体测试；观察区块重复加载和资源占用；给出真实游戏截图/录像与日志。
- 不应宣称“沉浸式传送门同等效果”，除非逐项验证。
- 与其他 Mod 的兼容不默认成立，单独列清支持范围和异常。
